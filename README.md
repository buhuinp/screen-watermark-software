# 屏幕水印

一个轻量的安卓全局悬浮水印工具。开启后水印会覆盖在所有应用之上，可自由设置文字、样式、颜色、字体与字号，参数修改实时生效，无需手动保存。

> 轻量 · 全局 · 悬浮水印

## 简介

屏幕水印通过系统悬浮窗（Overlay）把水印层绘制在所有应用之上，适用于内容防泄露、录屏/截图溯源、调试标注等场景。整个应用不依赖任何第三方库，纯系统框架实现，体积小、离线可用。

- 应用名：屏幕水印
- 包名：`com.buhuisy.app`
- 当前版本：v1.4

## 功能特性

- **全局悬浮**：水印覆盖所有应用，并延伸至状态栏 / 导航栏区域。
- **7 种水印样式**：`↗↙斜`（平铺）、`↖↘斜`（平铺）、`横向`（平铺）、`竖向`（平铺）、`单个居中`、`单个↗↙`、`单个↖↘`。
- **多行文本**：水印文字支持换行，同一文本块内按整体居中对齐。
- **调色盘取色**：HSV 色环 + 亮度条 + 透明度滑块，支持手动输入色号（`#RRGGBB` / `#AARRGGBB`）。
- **多彩渐变色**：可选开启，颜色沿文本从左到右流动。
- **自定义字体**：可导入本地 `.ttf` / `.otf` 字体文件，随时恢复默认。
- **字号调节**：8dp 起，自由拖动。
- **随机背景图 + 毛玻璃界面**：主界面自动加载随机背景图，卡片、按钮、对话框采用半透明磨砂玻璃样式。
- **实时保存**：所有参数修改即时写入本地存储并同步到悬浮水印，无需点击保存。

## 编译与运行

项目为标准的 Gradle 安卓工程，可用 Android Studio、Aide Pro 或命令行编译。

### 使用 Android Studio

1. 用 Android Studio 打开项目根目录。
2. 等待 Gradle 同步完成。
3. 连接设备或启动模拟器，点击运行。

### 使用命令行

```bash
# 在项目根目录执行
./gradlew assembleDebug
```

生成的 APK 位于：

```
app/build/outputs/apk/debug/app-debug.apk
```

### 使用 Aide Pro

直接用 Aide Pro 打开项目根目录即可编译。项目未引入任何第三方依赖，Aide 内置的 Gradle 与 JDK 通常可直接构建；若报语法 / JDK 版本错误，可在 `app/build.gradle` 的 `compileOptions` 中调整 `sourceCompatibility` / `targetCompatibility`。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `SYSTEM_ALERT_WINDOW` | 绘制全局悬浮水印（需在系统设置中手动授权）。 |
| `INTERNET` | 加载主界面的随机背景图。 |
| `MANAGE_EXTERNAL_STORAGE` / `READ_EXTERNAL_STORAGE` | 读取用户自备的字体文件。 |

悬浮窗权限需在系统设置中手动开启，应用首次启动时会引导跳转授权页。

## 使用说明

1. 首次启动按提示授予「悬浮窗」权限。
2. 在主页输入水印文字（回车可换行），按需选择样式、调节字号、导入字体。
3. 点击「打开调色盘」设置颜色、透明度，或开启渐变色。
4. 点击顶部按钮开启水印，水印即覆盖全局；再次点击关闭。

所有参数修改会实时保存并立即同步到悬浮水印。
